## ***ClassTrack*** - School Management System


***ClassTrack*** is a web app built to make school management a lot easier. From keeping track of students and teachers to managing subjects,lessons, attendance, and grades — it’s got the essentials covered in one simple and organized place.

---

###  Features

- Add and manage student records with ease  
- Assign teachers to subjects without the headache  
- Track daily attendance   
- PostgreSQL-powered backend for smooth data handling  
- Role-based login to keep everything secure and organized  


##  Tech Stack:

- **Frontend**: React, TypeScript  
- **Backend**: Next js 
- **Database**: PostgreSQL (with Prisma ORM)
